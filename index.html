Bolt Action Solo

Rules

Each enemy order dice

  1. Turn over the top Unit card. Choose one of the matching enemy units that has no order yet.
  2. If the unit can only do one specific order, give it that. Otherwise turn over the top Order card.
  3. If the unit can't make that order (off-table units need Run or Advance), put the card at the bottom of the Order pile and draw again.
  4. Make any Order Tests. The unit may go Down.
  5. Carry out the order.

End of turn

Make Recovery tests, put the order dice back in the bag, then shuffle the Unit and Order cards back into their piles. The app does this for you.

Rally

When you draw a Run order you can use it to rally, or send Down, any unit within 12" of the activated unit, as long as that unit doesn't already have an order dice. That unit then gets the order dice.

Order Card pile runs out

Shuffle the Order cards and start again. The app does this automatically.

Setting up

  • Pick both armies to an agreed points value.
  • Add one Unit card for each unit in the enemy force.
  • Use two Order cards per enemy order dice. A ratio of 3 Advance : 2 Fire : 1 Run is recommended, and you can change it.

Notes

Combat Level cards are not in the PDF this app is based on, so they aren't included. Solo play cards by Martin Otten. Fan-made aid for personal use; Bolt Action is a Warlord Games game.
